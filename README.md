# Reliability_aware-_mutisensor_IP

The multi-sensor interface IP based on Verilog HDL includes sensing of temperature, distance and gas, including range checking, timeout detection and health monitoring functions. The design of the component is tested with AMD Xilinx Vivado simulation as a joint venture performed by two collaborators.
